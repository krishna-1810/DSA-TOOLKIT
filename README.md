# DSA Toolkit

A custom Data Structures and Algorithms library in C++, built from scratch without using the STL.

## Modules
- Linked List
- Stack
- Queue
- Priority Queue (max-heap)
- Hash Table (chaining)
- Sorting: Bubble, Selection, Merge, Quick
- Searching: Linear, Binary

## How to Run
```
g++ main.cpp -o main
./main
```
(On Windows, run `main.exe`.)
